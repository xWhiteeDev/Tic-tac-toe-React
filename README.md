# ⚛ Tic-Tac-Toe

Simple tic-tac-toe game built with React and TypeScript.

## Features
- Two player game (X and O)
- Move history with ability to go back to any previous move
- Win detection with highlighted winning combination

## Tech stack
- React
- TypeScript
- Vite

## Getting started

```bash
npm install
npm run dev
```

## Project structure
- `src/components` — React components
- `src/types` — TypeScript types
- `src/styles` — CSS styles
